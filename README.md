## 快速开始

- **刚加入 CCS？** 先看 [成员手册](./CCS%20成员手册.md)。
- **想参与维护？** 看 [维护手册](./CCS%20维护手册.md)，然后向管理员申请权限。
- **你是管理员？** 看 [管理手册](./CCS%20管理手册.md) 和 [制度详解](./CCS%20制度详解.md)。
- **想了解 CCS 怎么运转？** 看 [制度详解](./CCS%20制度详解.md)。
